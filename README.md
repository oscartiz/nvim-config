# nvim-config

My Neovim configuration. Uses [lazy.nvim](https://github.com/folke/lazy.nvim) as the plugin manager.

## Install

One-liner:

```sh
curl -fsSL https://raw.githubusercontent.com/oscartiz/nvim-config/main/install.sh | bash
```

Existing `~/.config/nvim` is moved to `~/.config/nvim.bak.<timestamp>` before cloning.

## Requirements

- Neovim >= 0.9
- git
